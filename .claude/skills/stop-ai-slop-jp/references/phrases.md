# 撲滅すべき語彙の禁止リスト 8系統

機械的に検索できるリスト。1記事に同系統が複数出たら削るか言い換える。

## 1. AI偏愛語

泥臭さ / 手触り / 解像度(比喩用法) / 本質 / 熱量 / 思想(個人ブログ文脈) / 設計(比喩用法) / 装置(比喩用法) / 営み / 文脈(比喩用法) / 言語化 / 輪郭 / まなざし

言い換え: その語で何を言いたかったのかを具体に開く。「解像度が上がった」→「○○と△△の区別がつくようになった」

## 2. 必殺技造語(壮大化)

真理 / 虚飾 / 禁欲的 / 美学 / 境地 / 結末 / 覚悟 / 祈り / 呪い / 救い(日常の話題で)

言い換え: 実際に起きたことに戻す。「禁欲的な美学」→「機能を2つに絞った」

## 3. 横文字メタファー

思考のOS / 人生をハック / 習慣をインストール / マインドをリファクタリング / 自分をアップデート / 経験のポートフォリオ / 学びをストック

言い換え: 考え方を変える / 工夫する / 習慣をつける / 考え方を整理する / 経験を貯める

## 4. 戻せるカタカナ

コンテキスト→文脈・前提 / アライメント→すり合わせ / コミュニケーション→会話・連絡 / ポテンシャル→伸びしろ / インサイト→気づき / フィードバック→指摘 / コミット→引き受ける

固有の技術用語(API、トークン、デプロイ等)は対象外。日本語にした方が短く正確になる語だけ戻す。

## 5. 翻訳調動詞

示している / 指している / 物語っている / 象徴している / 収斂する / 浮き彫りになる / 結実する / 醸成される / 昇華する

言い換え: 主体を人間に戻す(structures.md の 1)。

## 6. ヘッジ・定型免責・締めの儀式

ケースバイケース / 場合によります / 〜と言えるでしょう / 〜かもしれません(連続) / あくまで個人の意見ですが / いかがでしたか / 参考になれば幸いです

言い換え: 立場を選ぶ。免責は本当に必要な1箇所だけ残す。

## 7. 副詞スタッキング・強度の飽和

非常に / めっちゃ / ガチで / 普通に / かなり / 圧倒的に / 劇的に / 〜すぎる(3回以上)

ルール: 1段落に2個以上重ねない。「すぎる」は1記事3回まで。強い言葉は本当に強い1箇所に取っておく。

## 8. 記号・絵文字のアーティファクト

全角ダッシュ ── / 中黒3項目並列(A・B・C) / `**` の残骸 / コロン後の半角スペース / 段落末の装飾絵文字(🚀🎯✨💡)の等間隔撒布 / 形容詞・心情の「」囲み

処理: 検索して全置換。──はコロン・改行・読点に。中黒は「と」「や」に。「」は固有名詞と直接引用だけ残す。
