# 避けるべき構造パターン 6系統

パターンごとに、検出のしかたと書き換えの型を示す。例は examples.md にもある。

## 1. false agency(モノ主語 + 人間の動詞)

モノや抽象概念が、人間にしかできない動詞の主語になっている文。行為の主体を隠すので、誰の判断か分からなくなる。

- 検出: 「データが示している」「文化が醸成される」「議論が収斂する」「設計が物語る」「課題が浮き彫りになる」
- 書き換え: 主体を名指しする。「データが示している」→「この数値を見て自分は○○だと判断した」。「文化が醸成される」→「チームの誰それが○○を始めて、周りが真似した」

## 2. 命題型H2(見出しの主張化)

見出しが「○○は△△だ」という文になっている。各節が小さなTED talkになり、本文が見出しの反復で終わる。

- 検出: H2/H3が文として読める。「継続こそが力になる」「ツールは思想を映す」
- 書き換え: 名詞句に戻す。「継続こそが力になる」→「3ヶ月続けた結果」。主張は本文の中で、根拠と一緒に書く

## 3. 決めつけ→反転の序文

「多くの人は○○だと思っている。しかし実際は△△だ」で始まる導入。読者を仮想的に間違わせてから訂正する型で、AIが最も好む。

- 検出: 冒頭2〜3文が「一般に〜と言われる」「〜と思われがちだ」→「だが」「しかし」
- 書き換え: 自分の話から入る。何を見た、何をした、何に困った、から始める

## 4. 二項対比・否定的列挙・劇的断片化

「AではなくB」「Aでもない、Bでもない、Cだ」「シンプル。それだけ。」のようなレトリックの多用。1回なら効くが、AIは全節でやる。

- 検出: 「単なる○○ではなく」「〜ではありません。〜なのです」。一語文の連続
- 書き換え: 直接Yを書く。「単なるツールではなく思想だ」→「このツールは○○という判断を強制する」

## 5. 全方位肯定・両論併記・儀式的disclaimer

「○○もあり、△△もあります」「ケースバイケースです」「あくまで個人の意見ですが」。どの立場からも反論されない代わりに、何も言っていない。壮大化(必殺技造語で個人の話を「真理」「美学」に膨らませる)もこの裏返しで、立場の不在を語彙で埋めている。

- 検出: 節末が毎回「〜も大切です」「バランスが重要です」で終わる。免責が各節に1個ずつある
- 書き換え: 選んだ方だけ書き、選ばなかった理由を1行添える。膨らませた抽象語は、実際に起きたことに戻す

## 6. 均一リズム・テンプレ反復

全段落が3〜5文、全段落が同じ強度で着地、文末が「です」「ます」で完全に一貫、「体験→引用→抽象化」の節構成が3回以上続く。個々の文は正しいのに、全体が機械的に見える原因。

- 検出: 段落の行数がほぼ同じ。音読すると息継ぎの位置が等間隔
- 書き換え: 一文だけの段落を作る。結論のない段落を残す。どこか1箇所、口語で崩す
